🎟️ Perq Prototype

End-to-end clickable prototype combining the best UI patterns from your favorite apps:

  • Home: Honey/Rakuten dashboard
  • Wallet: Apple Wallet stack → Bumble card on tap
  • Discover: Tinder-style swipe
  • Rewards: Duolingo + Starbucks tier ladder
  • Social: Instagram Stories + Strava feed
💡 Try these:
1. Tap any pass in Wallet — watch it expand to a Bumble-style detail card
2. Tap Discover, then ✕ / ♥ / ↗ buttons to swipe
3. Tap a category emoji on Home
4. Tap "Spin Now" on Rewards
